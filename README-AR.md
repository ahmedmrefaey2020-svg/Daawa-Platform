# Dawah دعوة — تركيب نسخة الأندرويد

ارفع كل الملفات دي في جذر مستودع GitHub (من غير مجلدات)، وبعدين Actions ← Build APK ← Run workflow.
الـworkflow بيعمل كل حاجة لوحده: بينسخ ملفات الجافا، وبيضيف الأذونات (الموقع + المنبّه الدقيق + البطارية + الإشعارات) والخدمة والـreceivers، وبيحمّل أذان افتراضي، وبيركّب **أيقونة التطبيق** من `icon-512.png`.

> ملاحظة: build-apk.yml لازم يتحط في `.github/workflows/build-apk.yml`.
> لازم ترفع كمان `icon-192.png` و`icon-512.png` (موجودين في الـzip).

## الجديد في الإصدار ده
- إصلاح خطأ `Cannot access 'natSig' before initialization` (كان بيحصل لما الأذان يكون مفعّل ويفتح التطبيق تاني).
- «مسح البيانات والبدء من جديد» بقى بيمسح كمان إعدادات الجهاز والنسخة الاحتياطية في تخزين الأندرويد (كانت بترجّع الإعداد المسبب للمشكلة).
- الموقع بيتطلب عن طريق إضافة `@capacitor/geolocation` (أضمن من طلب المتصفح داخل الـWebView).
- تحميل التلاوات الكاملة لأي قارئ (من تبويب التحميلات ← التلاوات)، والتلاوات النادرة والمحافل (تبويب «نادرة ومحافل»). الملفات بتتحفظ في `files/dl/` على الأندرويد وتتشغّل بدون نت.
- روابط التعلّم بتفتح في يوتيوب (من الجزء الأصلي).
- صفحة الأدمن بكود تحقق بيوصل على إيميل الأدمن (يتغيّر مع كل إرسال وكل محاولة غلط).
- صفحة التجويد: دروس يوتيوب + القراءات العشر وراوييها.

## إعداد Supabase (مرة واحدة)
1. شغّل `supabase-admin.sql` في SQL Editor.
2. Authentication ← Email Templates ← Magic Link: ضيف `{{ .Token }}` في نص الرسالة (عشان يظهر الكود).
3. Authentication ← SMTP: فعّل SMTP خاص — الإرسال الافتراضي من Supabase محدود جدًا.

## تحديث التطبيق من جوه التطبيق
1. افتح «لوحة الإدارة» من القائمة ← اطلب الكود ← اكتبه.
2. ارفع ملف `index.html` الجديد (واكتب الجديد في التحديث) ← نشر.
- التحديث ده للواجهة (index.html) فقط. أي تعديل في ملفات الجافا أو الأذونات لازم APK جديد.

## الجديد: التحميل والمتون والقرآن بالروايات
- **طابور تحميل موحّد**: أي زر ⬇ (في صفحة القارئ، تحت أي مشغّل، في التحميلات، في النوادر) بيضيف للطابور. تقدر تضغط على التلاوة اللي بعدها وهي بتتحمّل ومن غير «تحميل الكل». وفيه زر «تحميل الكل» لكل مجموعة (كل سور التسجيل). شريط صغير تحت بيوريك التقدم وزر إيقاف.
- **التشغيل من الجهاز**: لو التلاوة محمّلة بتتشغّل منها (حتى بدون إنترنت).
- **استرجاع التحميلات بعد مسح التطبيق**: قائمة اللي حمّلته بتتحفظ مع الحساب (نفس مزامنة البيانات الموجودة `udata/`). أول ما تسجّل دخول على تثبيت جديد بتظهر شاشة تسألك تحمّلهم تاني ولا لا (وكمان زر «استرجاع تحميلاتي» في التحميلات › المتون والقراءات). محتاج المزامنة السحابية تكون شغّالة.
- **متون القراءات نصًّا**: الشاطبية من GitHub (hanizeidan-svg/qiraat عبر jsDelivr)، والدرة المضية وطيبة النشر من turath.io API (الشاملة: 7749 و7795). قراءة + بحث + وضع الحفظ + حفظ بدون إنترنت + مفضلة للمتن ولكل باب.
- **القرآن بالروايات**: من Quranpedia API (`api.quranpedia.net/v1/mushafs`) — بيعرض الروايات اللي بيقدمها الـAPI فعلًا ويحفظها للقراءة بدون إنترنت. الأصوات بالروايات من mp3quran (زر 🎧).
- **طريق تعلّم القراءات**: التأسيس ← الشاطبية ← الدرة ← الطيبة ← التطبيق والإجازة، مع متابعة حفظ الأبواب وحاسبة معدل الحفظ.
- **المفضلة**: الفيديوهات (روابط يوتيوب) والمتون والروايات تتضاف للمفضلة.

## تحديثات أخيرة
- **أيقونات الأذان**: تشغيل ▶ ودوّارة تحميل وإيقاف (مربع مدوّر) وإعادة محاولة — بدل الرموز النصية القديمة، في صفحة الأذان وشاشة اختيار المؤذن.
- **٥٠ قارئ مجوّد إضافيين** (أصبحت القائمة المصرية ١٠٠): أسماؤهم من قائمة قرّاء إذاعة القرآن الكريم المصرية وتصنيف القرّاء المصريين في ويكيبيديا. كل واحد له ملف وتلاواته النادرة والمحافل والإذاعية والمجوّدة عن طريق البحث في archive.org (زرار لكل تصنيف). التواريخ والسير متروكة فاضية لحد التأكد منها.
- **لوحة الإدارة للأدمن فقط**: الزرار والصفحة بيظهروا بس لو الحساب المسجّل بإيميل الأدمن (`ADMIN_EMAIL`). ده إخفاء من الواجهة؛ الحماية الفعلية لسه بكود التحقق على الإيميل وسياسات Supabase (RLS).

## تحديث (نوفمبر ٢٠٢٦)
- **صفحة التحميلات**: تصميم جديد، أول تبويب «تحميلاتي» فيه زر **تشغيل الكل** وأسماء القرّاء المحمّلين وتحت كل واحد سهم ⌄ يفتح التلاوات المحمّلة (تشغيل/حذف لكل تلاوة أو للقارئ كله). متون الدرة وطيبة النشر اتشالت من التحميلات.
- **أزرار التحميل والانتظار والإيقاف** (في الطابور والأذان وشريط التحميل): أيقونات جديدة — انتظار (ساعة رملية)، جارٍ التحميل (دوّارة)، تم (✓)، إيقاف (مربع).
- **التلاوات النادرة**: صفحة النادرة والتحميلات فيها أسماء كل القرّاء (٢٠٠ + قرّاء مكتبة mp3quran) مع بحث بالاسم.
- **أفضل ٢٠٠ قارئ** مرتّبين تقريبًا بالشهرة، كل واحد له ملف وتلاوات نادرة وقراءاته. +٦٨ اسم ثابت، والباقي بيتكمّل تلقائيًا من مكتبة mp3quran (أولوية للمجوّدين) ويتحفظ.
- **ثبات التحميلات**: بعد قفل التطبيق بيتحقق من الملفات الفعلية على الجهاز ويسترجع القائمة منها (محتاج APK جديد لأن `DawaAdhanPlugin.java` اتعدّل: ملف `.meta` جانبي + دالة `list`).
- **بعد تسجيل الدخول**: لو مفيش تلاوات محمّلة على الجهاز بتظهر شاشة «أهلًا بعودتك — تحمّل تلاواتك تاني؟» بتلاواتك المحفوظة على الحساب (محتاج المزامنة السحابية).
- **القرآن بالقراءات**: مطابقة أدق للروايات؛ اللي نصه مش في الـAPI ليه رابط يوتيوب.
